# シフト表作成Webアプリ（GAS）Ver1.0

従業員のシフト希望を収集し、管理者が確定シフトを作成・管理できるGoogle Apps Script Webアプリケーションです。

## セットアップ手順

### 1. Google Apps Scriptプロジェクトの作成

1. [Google Apps Script](https://script.google.com/) にアクセス
2. 「新しいプロジェクト」を作成
3. `src/` フォルダ内の各ファイルをプロジェクトに追加:
   - `Code.gs` - メインエントリーポイント
   - `Auth.gs` - 認証モジュール
   - `DataAccess.gs` - データアクセス層
   - `AdminApi.gs` - 管理者用API
   - `UserApi.gs` - ユーザー用API
   - `ExcelExport.gs` - Excel出力
   - `index.html` - メインHTML
   - `css.html` - スタイルシート
   - `js.html` - クライアントサイドJS

### 2. スプレッドシートの準備

1. Google Driveで新しいスプレッドシートを作成
2. スプレッドシートのIDをコピー（URLの `/d/` と `/edit` の間の文字列）
3. GASプロジェクトの「プロジェクトの設定」→「スクリプトプロパティ」で `SPREADSHEET_ID` を設定
   - または、スプレッドシートに紐づくコンテナバウンドスクリプトとして作成

### 3. 初期セットアップ

1. GASエディタで `setupSpreadsheet` 関数を実行
2. 必要なシートとヘッダーが自動作成されます
3. デフォルト管理者アカウントが作成されます:
   - 社員番号: `admin`
   - パスワード: `admin`

### 4. Webアプリとしてデプロイ

1. 「デプロイ」→「新しいデプロイ」
2. 種類: 「ウェブアプリ」
3. 実行ユーザー: 「自分」
4. アクセス: 「全員」（組織内の場合は「組織内の全員」）
5. デプロイ

## データシート構成

| シート名 | 内容 |
|---------|------|
| Users | ユーザー情報（社員番号、氏名、権限、区分等） |
| MonthDefinition | 月度定義（開始日/終了日、適用開始年月度） |
| RequiredHolidays | 必要公休日数（年月度ごと） |
| Holidays | 祝日一覧 |
| ShiftOptions | 勤務時間選択肢 |
| ShiftRequests | 希望シフト（年月度×社員×日付） |
| ShiftFinal | 確定シフト（年月度×社員×日付） |
| Locks | 締切状態（年月度ごと） |

## 機能一覧

### 管理者（Admin）
- ユーザー登録/編集/パスワードリセット
- 月度設定（締め期間）管理
- 必要公休日の登録（年月度ごと）
- 祝日データの登録（Excel/CSV対応）
- 勤務時間候補の管理
- シフト希望の締切/解除
- 確定シフトの編集（過去月含む）
- Excel出力（勤務コード/公休形式）

### 一般ユーザー（User）
- シフト希望の入力（締切前のみ）
- 過去シフトの閲覧（編集不可）
- 他ユーザーの希望状況の閲覧（リアルタイム）
- パスワード変更
